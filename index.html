Foodlog

A photo-first food log that takes a few seconds per meal: photograph the plate, add a word or two, save. It works offline and syncs later, and Claude reads the photos through an MCP connector to estimate what was eaten, how much, and the nutrition. The demo has three days of made-up Kerala and German meals; anything you log stays in your browser.

  • TypeScript
  • PWA
  • Python
  • MCP

Recipie

An offline-first recipe PWA that knows what's in the pantry, so each recipe shows green, yellow or red for whether you can cook it right now. It has a step-by-step cook mode with timers, plus an MCP connector so Claude can read and save recipes. The demo uses a made-up pantry and eight Kerala dishes, and doesn't save your edits.

  • TypeScript
  • PWA
  • Python
  • MCP
